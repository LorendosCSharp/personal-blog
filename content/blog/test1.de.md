# Willkommen im Test-Blog

Dies ist ein Beispiel-Blogbeitrag zum Testen der **Nuxt Content**-Darstellung. Er enthält Überschriften, Listen, Zitate, Code-Blöcke, Tabellen, Bilder und mehr.

## Warum Markdown verwenden?

Markdown macht es einfach, Inhalte zu schreiben und dabei gut lesbar zu bleiben.

Einige Vorteile sind:

- Einfach zu lernen
- Gut für Versionskontrolle geeignet
- Portabel
- Unterstützt reichhaltige Formatierung

## Code-Beispiel

Inline-Code sieht so aus: `const message = "Hello World"`.

Ein Code-Block:

```ts
interface User {
  id: number
  name: string
}

const user: User = {
  id: 1,
  name: 'Alice'
}

console.log(user)
````
